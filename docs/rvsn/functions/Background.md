# Background

## rvsn.SetBackground

Set background on current scene

**Syntax**
`rvsn.SetBackground("/dev_hdd0/simple_test/images/musor_bg.png")`

**Parameters**
| Param | Type | Required | Desc |
| :--- | :--- | :--- | :--- |
| `filepath` | string | Yes | filepath to background image |

## rvsn.ClearBackground

Clear current background on current scene

**Syntax**
`rvsn.ClearBackground()`
