# TextBox

## rvsn.SetTextBox

Set textbox texture on current scene

**Syntax**
`rvsn.SetTextBox("/dev_hdd0/simple_test/images/textbox.png")`

**Parameters**
| Param | Type | Required | Desc |
| :--- | :--- | :--- | :--- |
| `filepath` | string | Yes | filepath to textbox image |

## rvsn.ClearTextBox

Clear current textbox on current scene

**Syntax**
`rvsn.ClearTextBox()`
