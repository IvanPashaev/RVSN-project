# Gamepad functions

## rvsn.IsGamepadButtonPressed

check if gamepad button pressed. Uses GamepadButtons enum(see in [GamepadButtons.md](../../rvsn/enums/GamepadButtons.md))

**Syntax**
`rvsn.IsGamepadButtonPressed(0,rvsn.GAMEPAD_BUTTON_RIGHT_FACE_LEFT)`

**Parameters**
| Param | Type | Required | Desc |
| :--- | :--- | :--- | :--- |
| `gamepad_number` | int | Yes | number of gamepad who need to check|
| `gamepad_button` | GamepadButtons | Yes | gamepad button|
